# MACI

Minimal Anti-Collusion Infrastructure: private, collusion-resistant on-chain voting with zk-SNARKs.
The lecture covers the problem MACI solves, the workflow and contracts, the cryptography and circuits
(keys, messages, chain hash, key change, poll joining, processing and tally), and what happened to the
project since 2024 (the 3327 anonymous poll joining grant, MACI v3.0.0, archiving of the repository).

The material follows MACI v3.0.0 (June 2026). In August 2026 the MACI repository was archived (read-only);
according to pse.dev the project is only monitored for bug fixes.
